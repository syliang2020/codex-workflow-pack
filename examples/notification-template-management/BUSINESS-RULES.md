## <a id="br-001"></a>BR-001 场景编码唯一

- 场景：新增或编辑模板。
- 触发条件：提交保存。
- 前端行为：必填校验，提示用户填写场景编码。
- 后端兜底：检查场景编码是否为空；同一场景编码不能重复创建启用模板。
- 失败结果：返回业务校验失败，并说明场景编码不可用。
- 边界条件：停用模板是否允许重复待确认。

## <a id="br-002"></a>BR-002 标题和正文必填

- 场景：新增、编辑和启用模板。
- 触发条件：保存或启用。
- 前端行为：标题和正文为空时阻止提交。
- 后端兜底：标题和正文为空时拒绝保存或启用。
- 失败结果：提示标题或正文不能为空。

## <a id="br-003"></a>BR-003 启用校验

- 场景：启用模板。
- 触发条件：管理员点击启用。
- 前端行为：二次确认。
- 后端兜底：检查模板存在、未删除、标题正文完整、场景编码有效。
- 失败结果：校验失败时保持原状态。

## <a id="br-004"></a>BR-004 预览不落库

- 场景：保存前预览。
- 触发条件：管理员输入示例变量后点击预览。
- 前端行为：展示预览标题和正文。
- 后端兜底：只进行变量替换和格式校验，不写入数据库。
- 失败结果：变量格式错误时返回错误说明。

## 待确认事项
