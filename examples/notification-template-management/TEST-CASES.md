## <a id="tc-001"></a>TC-001 场景编码唯一校验

- 前置条件：已存在同一场景的启用模板。
- 测试数据：重复 `sceneCode`。
- 操作步骤：
  1. 创建新模板。
  2. 输入重复场景编码。
  3. 提交保存。
- 期望结果：保存失败，提示场景编码不可用。

## <a id="tc-002"></a>TC-002 标题和正文必填

- 前置条件：进入模板创建或编辑页。
- 测试数据：标题为空或正文为空。
- 操作步骤：
  1. 清空标题或正文。
  2. 提交保存。
- 期望结果：前端阻止提交；绕过前端时后端返回业务校验失败。

## <a id="tc-003"></a>TC-003 启用校验

- 前置条件：存在停用模板。
- 测试数据：标题、正文完整的模板。
- 操作步骤：
  1. 点击启用。
  2. 确认操作。
- 期望结果：状态更新为启用；校验失败时状态不变。

## <a id="tc-004"></a>TC-004 预览不落库

- 前置条件：填写标题、正文和示例变量。
- 测试数据：正文包含变量占位符。
- 操作步骤：
  1. 点击预览。
  2. 查看预览结果。
  3. 不点击保存并刷新页面。
- 期望结果：返回替换后的预览内容；未产生新模板记录。
