# Prompt Preview Mode

适用于用户希望先生成完整 Codex 开发提示词，然后自行检查、修改、再复制执行的情况。

## 目标

只生成完整提示词，不执行开发。

## 限制

1. 不修改代码。
2. 不执行命令。
3. 不使用任何项目 MCP、数据库连接工具或迁移执行工具。
4. 不进入 `executing-plans`。
5. 不创建、不修改、不删除数据库对象。
6. 不运行测试。
7. 不生成虚假的测试结果。
8. 只输出可复制提示词。

## 输出格式

先输出任务判断：

- 工作模式
- 任务类型
- 分类置信度
- 判断理由
- 适用原因
- 假设条件和不确定点

然后输出：

```text
下面是可复制给 Codex 的完整开发提示词：
```

提示词内容必须包含：

1. 当前任务类型
2. 分类置信度和假设条件
3. superpowers 流程
4. 推荐 agent 或子代理职责
5. 项目上下文读取规则
6. 数据库规则
7. 接口规则
8. UI 规则
9. `writing-plans` 规则
10. `executing-plans` 规则
11. 子代理交接规则
12. 代码审查规则
13. 测试规则
14. Playwright 或浏览器真实测试规则
15. 验收输出要求
16. 【本次需求特殊要求】占位区

## 特殊要求占位区

生成的完整提示词必须包含：

```text
【本次需求特殊要求】
- 在这里追加本次需求的特殊限制
- 例如：只做后端、不改数据库、不改已有接口、必须兼容旧数据、必须补 Playwright 用例
```

不得替用户编造特殊要求。

## 结束提醒

最后输出：“你可以先检查这份提示词，如果本次需求有特殊要求，可以在【本次需求特殊要求】部分追加后再发给 Codex。”
