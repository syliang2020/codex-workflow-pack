# UI Checklist

适用于所有涉及前端页面、交互或体验的需求。

## UI 方案必须包含

1. 页面入口。
2. 页面路由。
3. 用户角色和权限可见性。
4. 页面主要区域。
5. 表格字段。
6. 查询条件。
7. 表单字段。
8. 新增流程。
9. 编辑流程。
10. 删除、禁用或启用流程。
11. 详情流程。
12. 空状态。
13. 加载态。
14. 错误态。
15. 表单校验。
16. 成功提示。
17. 失败提示。
18. 与接口字段的映射关系。

## 实现规则

1. UI 交互边界确认前，不要大规模写页面。
2. 不擅自新增需求外页面。
3. 不擅自改变已有全局交互规范。
4. 如果接口缺失，必须停下来输出接口变更建议。
5. 前端实现后必须执行构建检查。
6. 涉及关键路径时，必须执行 Playwright 或浏览器真实测试。
