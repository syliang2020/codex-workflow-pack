# Database Checklist

适用于所有涉及数据库的需求。

## 数据库设计前

必须先确认：

1. 是否已有相关表。
2. 是否需要新增表。
3. 是否需要修改已有表。
4. 是否需要迁移历史数据。
5. 是否涉及唯一约束。
6. 是否涉及索引。
7. 是否涉及逻辑删除。
8. 是否涉及审计字段。
9. 是否涉及租户、组织、权限边界。
10. 是否影响已有查询或报表。

## 数据库方案必须包含

1. 表结构设计。
2. 字段说明。
3. 字段类型和长度。
4. 默认值。
5. 是否必填。
6. 索引设计。
7. 唯一约束。
8. 外键或逻辑关联。
9. 兼容性影响。
10. 回滚方案。

## 执行规则

1. 本 skill 不固化项目专属数据库 MCP。
2. 真实执行数据库变更前，必须读取项目 `AGENTS.md` 或项目数据库规范。
3. 用户确认前，只能输出 DDL 草案、迁移脚本或人工执行说明。
4. 用户确认后，才可以按项目规则执行数据库变更。
5. 如果项目没有数据库工具，只输出脚本和人工执行说明。
6. 不得执行未经确认的建表、改表、删表、清表或数据迁移。
