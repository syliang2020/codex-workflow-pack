# API Contract Checklist

适用于所有涉及接口的需求。

## 接口契约必须包含

1. 接口名称。
2. 接口路径。
3. 请求方式。
4. 权限要求。
5. 请求参数。
6. 请求体结构。
7. 响应结构。
8. 分页规则。
9. 排序规则。
10. 状态码。
11. 异常返回。
12. 字段含义。
13. 是否兼容已有前端。
14. 是否影响已有接口调用。
15. 是否需要接口版本控制。

## 设计规则

1. 接口契约确认前，不要大规模实现前后端调用。
2. 前后端字段命名必须一致。
3. 分页、搜索、排序、枚举值必须明确。
4. 权限失败、参数错误、数据不存在、重复提交等异常必须明确。
5. 如果修改已有接口，必须说明兼容性影响。
