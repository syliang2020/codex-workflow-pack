# Bugfix Checklist

适用于所有 bug 修复需求。

## bug 修复前必须输出

1. bug 现象。
2. 复现步骤。
3. 期望结果。
4. 实际结果。
5. 初步影响范围。
6. 根因证据。
7. 最小修复方案。
8. 回归测试方案。

## 如果无法复现

1. 不得盲改。
2. 必须说明无法复现的原因。
3. 可以增加日志、断点、测试用例或排查步骤。
4. 经用户确认后，才可以进行防御性修复。

## 修复规则

1. 默认最小改动。
2. 不做需求外重构。
3. 不扩大功能范围。
4. 不擅自修改接口契约。
5. 不擅自修改数据库结构。
6. 修复后必须执行回归测试。
